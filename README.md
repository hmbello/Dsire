#Dsire
Project repository for Dsire
Dsire Marketplace

Tagline: The market that meets your desires.


Dsire is a mobile-friendly marketplace prototype created as a learning project for GitHub, web development, and cloud computing.


Features in this first version


Responsive layout for Android phones and desktop browsers

Product category filters

Product search

Sample product cards and Nigerian naira prices

Client-side demo cart and subtotal

No account, database, order processing, or payment collection


Run it

Open index.html in a browser. The first version uses plain HTML, CSS, and JavaScript, so no build tools are required.


Publish with GitHub Pages


Create a GitHub repository named dsire-marketplace.

Upload index.html and README.md to the repository root.

Open Settings → Pages.

Under build/deployment, choose Deploy from a branch.

Select the main branch and / (root), then save.

Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

Important

All products and prices are examples. The cart runs only in the browser. This prototype does not process orders or payments and must not be represented as a live marketplace.
